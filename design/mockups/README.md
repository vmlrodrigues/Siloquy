# Design mockups

Static prototypes used to settle a design before building it. Not shipped, not
referenced by the app — they exist so an issue can show what was agreed rather
than describe it.

Each `.html` is self-contained and opens in a browser. The `.png` beside it is
what gets embedded in the GitHub issue, rendered with:

```
qlmanage -t -s 1800 -o out design/mockups/<name>.html
```

then trimmed to its content.
