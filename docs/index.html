Siloquy

On-device speech-to-text for macOS — private, fast, no cloud required

Download for Mac

macOS 14 Sonoma or later  ·  Apple Silicon required (M-series)

What Siloquy does

Press a shortcut, speak, release — your words appear at the cursor in any app. Everything runs on your Mac. No account, no subscription, no audio ever leaves your device.

Speech-to-text On-device
Supports local and cloud transcription models. Parakeet V2 (on-device, Apple Silicon) is recommended for English — it delivers the lowest word-error rate of the open-source local models (~6%) while transcribing thousands of times faster than real time, with no internet connection required. Other languages use Apple Speech or Parakeet V3, picked per language.
AI Enhancement On-device
After transcribing, an on-device AI model cleans up grammar, removes filler words, and fixes self-corrections — all without an API key or server. You can also connect a cloud provider if you prefer.
Many languages On-device
Give each language you speak its own shortcut. One keystroke switches the transcription model, the clean-up prompt and the translation tiles together — so dictating in Portuguese is as immediate as dictating in English.
Power Mode
Save different enhancement profiles per app or website. Your coding environment can get a different prompt than your email client.

1 Install

  1. Download and open the DMG
    Drag Siloquy to your Applications folder, then launch it.
  2. Grant Microphone access
    Required to hear you speak. The onboarding flow will prompt you.
  3. Grant Accessibility access
    Required to paste text at the cursor in other apps.
  4. Grant Input Monitoring access
    Required for your recording shortcut to work when another app is in focus.

2 Download the transcription model

Recommended: Parakeet (local) — download it once from the Dictation Models screen, then it runs entirely on your Mac with no internet required.
  1. Open Siloquy → Dictation Models
    Click the Local tab.
  2. Find Parakeet and click Download
    Parakeet V2 is 474 MB. Download happens once — it stays on disk between launches. If you speak more than English, see Dictate in another language below.
  3. Select Parakeet as your active model
    Click the model to make it active. You should see it appear in the main status bar.

3 Set your shortcut and speak

  1. Open Settings → Shortcuts
    A setup that works well: Right ⌘ to start and stop recording, and Right ⌥ to toggle AI Enhancement on or off. Both keys are easy to reach and rarely conflict with other shortcuts.
  2. Click in any text field in any app
    Siloquy pastes wherever the cursor is.
  3. Press your shortcut, speak, press again
    The mini recorder appears while you speak. Press again to transcribe. The result is pasted automatically.

AI Enhancement

Enhancement takes the raw transcript and passes it through an AI model to fix grammar, remove fillers, and handle self-corrections. The default is the on-device Gemma model — no setup needed beyond downloading it once.

On-device No API key
AI Enhancement → Provider: Local (On-device). Download Gemma 4 E4B when prompted (3.4 GB); on a Mac with less memory, Gemma 4 E2B is a lighter 2.4 GB fallback. Runs via Metal on Apple Silicon — typically 2–3 seconds for a typical dictation.
Cloud providers API key required
Groq and Cerebras both have generous free tiers. Go to AI Enhancement, pick a provider, paste your API key. Groq llama-3.3-70b or Cerebras llama-3.3-70b are good starting points.

You can turn enhancement off per dictation, in which case the raw transcript is pasted directly — but the on-device model is quick enough that there is rarely a reason to.

Enhancement prompts

Prompts control how the AI model handles your transcript. Switch between them instantly with ⌘1 ⌘2 ⌘3 and so on while enhancement is enabled — the icon on the recorder updates to show which one is armed. The order is fixed, so a shortcut always means the same thing. You can add your own.

Default ⌘1
The standard cleanup mode. Removes filler words, fixes grammar and self-corrections, and uses any clipboard or screen context to resolve ambiguous words. The model is instructed to act purely as a transcription cleaner — it will not respond to questions or commands in your speech, only tidy them up and pass them through.
Assistant ⌘2
Turns the AI into a general assistant. Instead of cleaning up your words, it acts on them — so you can dictate "give me three bullet points summarising this" or "rewrite that more formally" and the result is pasted directly. Useful when you want to speak a question or instruction and paste the answer, rather than the words you said.
Translation tiles ⌘3 and beyond
One per language you dictate in, generated for you rather than written by hand — To Portuguese, To Spanish, and so on. Each keeps a fixed key, so it means the same thing whichever language you are speaking. See Dictate in another language below.
The right prompt for the model, automatically. On the Local (On-device) provider, ⌘1 sends the prompt that measured best with the model you picked — the fuller one for Gemma 4 E4B, a shorter one for E2B, which follows brief instructions more reliably. Nothing to configure.
Create your own: in AI Enhancement, find Enhancement & Translation Prompts and click ＋. Custom prompts sit after Default and Assistant, and you can limit one to a single dictation language if it only makes sense there.

Dictate in another language

Set up the languages you speak and give each one a shortcut. Pressing it switches everything at once — the transcription model, the clean-up prompt, and the translation tiles — so there is nothing to change per session.

A model chosen per language On-device
English keeps Parakeet V2, which is English-only but the strongest on English. Other languages use Apple Speech, which ships a separately tuned asset per locale and tells European Portuguese apart from Brazilian. Dutch uses Parakeet V3 (English plus 25 European languages), since Apple has no Dutch model. You can override the choice for any language.
Clean-up written in your language
The clean-up prompt is not an English prompt pointed at another language — it is written in that language and states its own conventions for numbers, currency, dates and times. Portuguese (Portugal and Brazil), Spanish, French, German, Italian and Dutch each have one, so "quatro mil e quinhentos euros" comes back as "4500 €". ⌘1 keeps meaning "clean this up properly" whatever you are speaking.
Translation, without setting anything up
Every language you add gets its own translation tile with a permanent ⌘ key. The key never moves when you switch language, and the tile for the language you are currently speaking is shown inert — there is nothing to translate into the language you are already using.
  1. Open Dictation Models → Dictation Languages
    Click Add a language… and pick one. English is always there.
  2. Download what it needs
    The row says whether a model is ready for that language, and offers the download if not. Apple Speech assets come from macOS itself and need macOS 26 or later.
  3. Give it a shortcut
    Click Record on the row and press the keys you want. Any modifier combination works.
  4. Press it and start speaking
    The language flashes under the notch so you know it took, and the menu bar shows which one is active. Clicking a row switches language too.

Tips

Self-corrections
Say "scratch that", "actually", or "no wait" mid-sentence and the enhancement model will discard the earlier version and keep only the correction.
English variant
AI Enhancement → gear icon → English variant. Choose Australian, British, Canadian, or American. The AI enhancement output will use that spelling.
Personal dictionary
Add names, technical terms, or brand names in Dictionary. The AI enhancement model will preserve those spellings exactly.
Power Mode
Create per-app profiles with different prompts and providers. Useful if you dictate in very different contexts — technical notes vs. casual messages, for example.
Live text preview
Settings → Show Live Text Preview shows the words in the recorder as you speak. It needs a streaming model — Parakeet and Apple Speech both stream, so it works whichever language you are in.
Translating into a language you don't dictate in
Translation tiles come from your dictation languages, so the quickest route is to add the destination as a language. If you want a destination you will never speak, write an ordinary prompt for it — "Translate the text into X. Output only the translation." — and it takes a ⌘ key like any other.
